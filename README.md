# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

> 이 README 는 스타터에 들어 있던 것입니다. 제출 전에 아래 \*\*\[학생 작성]\*\* 부분을 직접 채우세요.

## 실행 방법

* Python 3.10–3.13, pygame 2.x

  * Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

|키|동작|
|-|-|
|← / →|좌우 이동|
|Space|시작 화면에서 게임 시작 / 게임 중 총알 발사|
|R|게임 오버 후 다시 시작|
|Esc|종료 (시작 화면에서도)|

## 파일 구성

|파일|내용|
|-|-|
|`main.py`|게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버|
|`entities.py`|그림 불러오기(`load\_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy`|
|`settings.py`|화면 크기·속도·색 같은 상수|
|`assets/`|그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`)|
|`AI\_USAGE.md`|생성형 AI 사용 기록|

## 구현한 기능

<!-- 구현한 기능을 확인할 것. 예: - \[x] F1 플레이어 이동 — 방향키 좌우 이동, 화면 밖으로 나가지 않음 -->

* \[x] F1 플레이어 이동

  * 왼쪽 및 오른쪽 방향키로 플레이어 이동
  * 화면 밖으로 나가지 않도록 이동 범위 제한



* \[x] F2 총알 발사

  * 스페이스바를 누르면 총알 발사
  * 총알이 위쪽으로 이동
  * 화면 밖으로 나간 총알 삭제
* \[x] F3 적 명중과 점수

  * 총알과 적의 충돌 판정
  * 충돌한 총알과 적 제거
  * 적 1대 명중 시 10점 증가
  * 게임 화면에 현재 점수 표시
* \[x] F4 피격과 게임 오버

  * 적과 플레이어 충돌 시 생명 감소
  * 적이 화면 아래로 지나가면 생명 감소
  * 생명이 0 이하가 되면 게임 오버
  * 게임 오버 화면에 현재 점수 표시
* \[x] F5 재시작과 최고 점수

  * 게임 오버 후 R키로 재시작
  * 최고 점수를 highscore.txt에 저장
  * 프로그램 재실행 시 최고 점수 유지
  * 게임 오버 화면에 최고 점수와 재시작 안내 표시
